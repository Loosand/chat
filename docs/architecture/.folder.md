# Folder: docs/architecture

1. **地位**：跨 package 的架构规则、主流程和同步协议事实源。
2. **逻辑**：记录代码无法独立表达的边界、状态机、部署取舍和文档维护规则，并与少量核心源码双向锚定。
3. **约束**：引用源码优先使用类型/函数名等稳定锚点；规划与已实现必须明确区分。
