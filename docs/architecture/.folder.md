# Folder: docs/architecture

1. **地位**：跨 package 的架构规则、主流程和同步协议事实源。
2. **逻辑**：记录代码无法独立表达的边界、状态机、部署取舍和文档维护规则，并与少量核心源码双向锚定。
3. **约束**：引用源码优先使用类型/函数名等稳定锚点；规划与已实现必须明确区分。

## 成员清单

- `auth.md`：Better Auth 边界、首期能力、插件分期、migration 与双部署安全规则。
- `chat-core.md`：聊天领域模型、原子 turn、run 状态机、checkpoint 和 repository 边界。
- `deployment.md`：Vercel/Docker 构建 profile、显式 migration、环境与能力矩阵。
- `frontend-stack.md`：Base Rhea、Chat primitives、Streamdown、UIMessage parts、滚动和刷新恢复的前端技术基线。
- `fractal-documentation-guide.md`：根 README、目录地图、源码 Header 和深度文档的同步法典。
- `implementation-goals.md`：长期 Goal、退出条件与功能级原子提交协议。
- `model-catalog.md`：四层模型目录、稳定协议/capability、credential reference、migration 与后续路由边界。

**触发器**：新增架构文档、修改横切约束或建立新的 `[DOC]` 锚点时，同步更新本文档。
