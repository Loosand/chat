# Folder: docs

1. **地位**：当前产品/架构事实、解释性读物与历史研究的长期文档入口。
2. **逻辑**：`architecture/` 描述当前项目范围和横切规则，`guides/` 面向非专业读者解释概念；DEEIX 研究文档只提供局部方案参考，不定义产品路线。
3. **约束**：必须声明审计时间和实现状态；Guide 不替代事实源；不得把目标设计写成当前代码能力。

## 成员清单

- `DEEIX_FEATURE_INVENTORY.zh-CN.md`：DEEIX 源码级功能事实库，作为历史研究保留。
- `DEEIX_REIMPLEMENTATION_ARCHITECTURE.zh-CN.md`：曾经的 DEEIX 等价复刻研究方案，不再作为当前产品目标。
- `architecture/`：当前项目架构规范，包含身份、聊天核心、部署、前端栈与分形文档协议。
- `guides/`：面向非专业读者的概念解释与阅读指南。

**触发器**：文档增删、重命名或事实源变化时，同步更新本文档与根 README。
