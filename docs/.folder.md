# Folder: docs

1. **地位**：产品研究、目标方案与架构规则的长期文档入口。
2. **逻辑**：研究文档描述参考系统与目标能力，`architecture/` 描述当前项目必须遵循的横切规则。
3. **约束**：必须声明审计时间和实现状态；不得把目标设计写成当前代码能力。
