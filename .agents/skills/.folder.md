# Folder: .agents/skills

1. **地位**：集中维护 Chat 项目可调用的 Agent Skills。
2. **逻辑**：每个子目录以 `SKILL.md` 为入口；大型 Skill 将细则拆到同目录的 references、reference、guides、examples、rules 或 agents 中渐进加载。
3. **约束**：Skill 的目录名与 frontmatter `name` 应一致；迁入的源项目案例必须明确标注，不能覆盖根 `AGENTS.md` 的项目约束或虚构当前实现。

## 成员清单

- `code-simplifier/`：在保持行为不变的前提下简化最近改动的代码。
- `coss-ui/`：coss/Base UI 组件、组合、样式和迁移参考。
- `fractal-document/`：代码、目录地图和架构文档的强制同步协议。
- `improve/`：只读代码库审计与可交接实施计划工作流。
- `next-best-practices/`：Next.js 文件约定、RSC、数据、路由和打包规则。
- `next-cache-components/`：Next.js Cache Components 核心概念和 API 参考。
- `next-cache-components-adoption/`：Cache Components 启用与逐路由采用流程。
- `next-cache-components-optimizer/`：Cache Components 静态壳与即时导航优化流程。
- `next-dev-loop/`：结合 Next.js MCP 与真实浏览器的运行时验证循环。
- `nextjs-data-caching/`：从源项目迁入的 Next.js 数据缓存案例与失效策略参考。
- `react-best-practices/`：React/Next.js 性能规则库。
- `react-hydration-boundaries/`：RSC、客户端交互和持久化状态的 hydration 边界设计。
- `swr/`：SWR 客户端取数、缓存、分页和 mutation 模式。
- `technical-writing/`：面向内部评审的中文技术写作规范。
- `trigger-dev/`：Trigger.dev v4 任务、编排、重试、实时与配置指南。

**触发器**：Skill 增删、改名、职责变化，或入口与配套资料的组织方式变化时更新本文档。
