# Folder: .agents

1. **地位**：保存本仓库可随项目版本演进的 Agent 工作规范与能力入口。
2. **逻辑**：`skills/` 按任务类型提供渐进式说明，Agent 先读取对应 `SKILL.md`，再按需加载同目录 references、guides、examples 或 rules。
3. **约束**：不得把 Skill 中的示例项目、规划能力或第三方约定写成 Chat 的已实现事实；项目级约束始终以根 `AGENTS.md` 和分形文档为准。

## 成员清单

- `skills/`：项目级 Agent Skills 与配套参考资料。

**触发器**：新增或删除 Agent 能力目录、改变 Skill 加载约束或 `.agents` 的职责时更新本文档。
