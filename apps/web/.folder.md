# Folder: apps/web

1. **地位**：Chat 唯一 Web 产品入口，承载未来用户端、管理端、HTTP API 与 Vercel/Docker Web 运行时。
2. **逻辑**：App Router 组合 `@repo/*` 包；`server/` 在请求时装配 Better Auth、共享 PostgreSQL、模型目录、AI/chat-engine 与 Resend，`lib/` 提供安全浏览器 client，共享 UI 与配置来自 workspace packages，Web 样式入口使用 Lerpwind 提供连续响应式尺度。
3. **约束**：默认 Node.js runtime 和 Server Component；业务规则不得只写在页面；Vercel 使用原生输出，自托管与 Docker 使用 `output: standalone`。

## 成员清单

- `app/`：App Router 页面、layout 和应用样式入口。
- `components/`：认证与持久聊天的产品级 feature components。
- `lib/`：浏览器安全的共享 client 与 helper。
- `server/`：请求时环境、基础设施和认证 composition root。
- `components.json`：Base Rhea + Base UI 应用 workspace 配置，将 UI 组件路由到 `@repo/design-system`。
- `package.json`：Web、auth/chat/chat-engine/model/network/database/Resend、AI SDK React/durable transport、Lerpwind 构建期插件与包含 `next typegen` 的工程命令。
- `next.config.ts`：共享 Next.js 配置入口，区分 Vercel 与 standalone 输出。
- `postcss.config.mjs`：Tailwind CSS v4 PostCSS 配置。
- `tsconfig.json`：Next.js TypeScript 配置。
- `vitest.config.mts`：让 Web 测试与 Next.js/TypeScript 共用 `@/` 路径语义。
- `next-env.d.ts`：Next.js 生成式类型声明入口，不手工维护 Header。

**触发器**：路由、运行时、Web 依赖、样式入口或部署输出变化时，同步更新本文档、根 README 和 `design.md`。
