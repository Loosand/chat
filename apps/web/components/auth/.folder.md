# Folder: apps/web/components/auth

1. **地位**：首期邮箱密码认证和当前 session 退出的浏览器交互组件。
2. **逻辑**：使用唯一 `authClient` 调用 Better Auth，统一安全错误映射、提交状态、成功引导与受保护页面退出行为。
3. **约束**：不得回显服务端原始错误；注册/重置保持防账号枚举文案；成功登录只导航到 `/chat`，退出只导航到 `/sign-in`。

## 成员清单

- `auth-card.tsx`：共享认证页面 Card、标题与辅助链接布局。
- `email-auth-form.tsx`：登录/注册表单和邮箱验证等待状态。
- `password-recovery-form.tsx`：忘记密码与 token 重置表单。
- `sign-out-button.tsx`：退出当前 session 并返回登录页。
- `safe-auth-error.ts` / `.test.ts`：按流程/错误码映射固定用户文案。

**触发器**：认证步骤、client 方法、redirect 或错误语义变化时同步本文档和 `docs/architecture/auth.md`。
