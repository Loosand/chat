# Folder: apps/web/components

1. **地位**：Web 产品级可复用 feature component 目录。
2. **逻辑**：组合 `@repo/design-system`、浏览器 client 与页面状态；基础 primitive 仍由 design-system 拥有。
3. **约束**：不得连接数据库、读取 server secret 或复制 shadcn primitive；服务端业务规则留在 package/Route Handler。

## 成员清单

- `auth/`：Better Auth 登录、注册、验证提示与密码恢复界面。

**触发器**：feature 目录、浏览器依赖或页面组合职责变化时同步本文档和 `apps/web/.folder.md`。
