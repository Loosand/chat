# Folder: apps/web/components/chat

1. **地位**：Goal 2 持久文本聊天的浏览器 UI feature。
2. **逻辑**：`ChatWorkspace` 用 AI SDK `useChat` 组合 durable transport，MessageScroller/Streamdown 渲染持久消息，composer 提交模型和文本。
3. **约束**：浏览器断开不等于取消；停止必须命中持久 cancel API；用户文本不渲染 Markdown；未知 part 不猜测展示。

## 成员清单

- `chat-workspace.tsx`：初始 snapshot、AI SDK 状态、URL、错误和 cancel 的组合根。
- `chat-message-list.tsx`：用户纯文本、assistant Markdown、reasoning summary 与来源标签渲染。
- `chat-composer.tsx`：模型选择、文本输入、发送和停止操作。

**触发器**：消息 part、transport、刷新语义、停止行为或页面布局变化时同步本文档和 frontend-stack/chat-http 文档。
