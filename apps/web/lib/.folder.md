# Folder: apps/web/lib

1. **地位**：Web 浏览器侧共享实例、wire 校验和轻量 transport/helper 目录。
2. **逻辑**：只组合对前端安全的公开依赖；聊天响应先校验再映射到 AI SDK UI 状态，服务端 composition 位于 `server/`。
3. **约束**：不得包含 secret、数据库连接、provider key 或 server-only package。

## 成员清单

- `auth-client.ts`：同 origin Better Auth React/Admin client 实例。
- `app-route.ts`：Next typedRoutes 与 TypeScript 7 静态导航泛型的集中适配。
- `chat-api-client.ts`：same-origin fetch、公开错误和 Zod response 校验边界。
- `chat-message.ts` / `.test.ts`：持久 MessageResource 到 ChatUIMessage 的纯转换。
- `durable-chat-transport.ts` / `.test.ts`：Chat run/checkpoint SSE 到 AI SDK UIMessageChunk 的 durable transport。

**触发器**：共享 client、依赖方向或浏览器配置变化时同步本文档和 Web 地图。
