# Folder: apps/web/lib

1. **地位**：Web 浏览器侧共享实例和轻量 helper 目录。
2. **逻辑**：只组合对前端安全的公开依赖；服务端 composition 位于 `server/`。
3. **约束**：不得包含 secret、数据库连接、provider key 或 server-only package。

## 成员清单

- `auth-client.ts`：同 origin Better Auth React/Admin client 实例。
- `app-route.ts`：Next typedRoutes 与 TypeScript 7 静态导航泛型的集中适配。

**触发器**：共享 client、依赖方向或浏览器配置变化时同步本文档和 Web 地图。
