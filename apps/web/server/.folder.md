# Folder: apps/web/server

1. **地位**：Next.js Web 的 server-only composition root 与平台 adapter 目录。
2. **逻辑**：请求时解析环境、创建基础设施 handle，并把 `@repo/*` 组合进 Route Handler/RSC。
3. **约束**：不得在 import/build 阶段连接外部系统；配置必须先校验，敏感值不进入客户端或日志。

## 成员清单

- `auth-env.ts`：Better Auth/PostgreSQL/Resend 环境校验和精确 origin 解析。
- `auth-env.test.ts`：Docker/Vercel production/preview 配置与拒绝边界测试。
- `auth-email.ts`：Resend 认证邮件与 request background task adapter。
- `auth-email.test.ts`：任务注册、HTML escaping 与 Resend 成败路径测试。
- `auth.ts`：惰性 auth/共享 database composition 与权威 session→OwnerId helper。
- `chat-runtime.ts`：Chat/ModelCatalog/AI/chat-engine 的惰性生产 composition root。
- `chat-run-manager.ts` / `.test.ts`：同进程 run 去重、显式 Abort 加速与清理 adapter。
- `chat-http.ts` / `.test.ts`：身份、Origin、有限 JSON、公开 resource/SSE snapshot 与错误映射边界。
- `model-bootstrap.ts` / `.test.ts`：`CHAT_MODEL_*` 首模型解析、四层目录幂等补齐与冲突保护。

**触发器**：server composition、环境变量、基础设施生命周期或授权边界变化时，同步本文档、Web 地图与架构文档。
