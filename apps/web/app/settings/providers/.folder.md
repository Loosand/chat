# Folder: apps/web/app/settings/providers

1. **地位**：Learning Chatbot v1 用户供应商管理的 App Router 入口。
2. **逻辑**：总览页合并固定 preset 与 owner 配置；详情页通过 Server Actions 完成保存、连通性检查和删除。
3. **约束**：API Key 只能经 password 字段提交到 server action；页面模型只含 `hasCredential`，不得回显明文或密文。

## 成员清单

- `[preset]/`：单个兼容供应商的详情与编辑页。
- `actions.ts`：重新认证、边界解析、保存/检查/删除和安全重定向文案。
- `page.tsx`：五种固定 preset 的 owner-scoped 配置总览。

**触发器**：preset、表单字段、操作语义或安全文案变化时同步本文档、子地图和 model-catalog 文档。
