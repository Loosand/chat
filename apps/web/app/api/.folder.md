# Folder: apps/web/app/api

1. **地位**：Web 产品的 HTTP Route Handler 根目录。
2. **逻辑**：每个 API 子目录只做协议、身份和应用服务装配，业务规则下沉到 `@repo/*`。
3. **约束**：默认 Node.js runtime；外部输入先校验，错误不得泄露密钥、token、SQL 或内部堆栈。

## 成员清单

- `auth/`：Better Auth catch-all HTTP 入口。
- `chat/`：conversation、公开模型、run、SSE checkpoint 与显式取消入口。

**触发器**：增加/删除 API 域或改变协议/运行时边界时，同步本文档、Web 地图和相关架构文档。
