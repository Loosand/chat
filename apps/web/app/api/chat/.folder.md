# Folder: apps/web/app/api/chat

1. **地位**：认证用户聊天、公开模型与可恢复 run 事件的 HTTP API 域。
2. **逻辑**：Route Handler 只做身份/Origin/input/output 装配，业务事实由 ChatService、ModelCatalogService 与 chat-engine 负责。
3. **约束**：Node runtime；写请求精确 Origin；所有聊天资源 owner-scoped；浏览器断开事件订阅不得取消执行。

## 成员清单

- `conversations/`：创建会话与按 active leaf 恢复分支。
- `models/`：公开且可用的 chat 平台模型列表。
- `runs/`：幂等创建/恢复 run、snapshot、SSE checkpoint 和显式取消。

**触发器**：API 域、方法、wire contract、鉴权或执行调度变化时同步本文档、父目录地图和 `docs/architecture/chat-http.md`。
