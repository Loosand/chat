# Folder: apps/web/app/api/chat/conversations/[conversationId]

1. **地位**：单个 conversation 的刷新恢复 resource。
2. **逻辑**：GET owner-scoped 读取 conversation，并从 active leaf 恢复当前 root-to-leaf 消息分支。
3. **约束**：不返回 owner/internal facts；空会话返回空 messages。
