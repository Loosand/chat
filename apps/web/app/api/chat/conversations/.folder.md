# Folder: apps/web/app/api/chat/conversations

1. **地位**：认证用户 conversation HTTP collection/resource。
2. **逻辑**：collection POST 创建 owner-scoped conversation；动态 resource GET 返回 conversation 与 active branch。
3. **约束**：创建必须验证 Origin/body；读取不存在或他人资源统一 404。

## 成员清单

- `route.ts`：`POST /api/chat/conversations`。
- `[conversationId]/`：conversation snapshot resource。

**触发器**：方法、字段或权限变化时同步本文档、上级地图和 chat-http.md。
