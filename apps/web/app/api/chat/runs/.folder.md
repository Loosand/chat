# Folder: apps/web/app/api/chat/runs

1. **地位**：认证用户 chat run 的幂等 collection 与可恢复资源域。
2. **逻辑**：POST 原子准备 turn/run 并用 `after()` 注册执行；动态资源提供 snapshot、SSE checkpoint 和取消。
3. **约束**：重复 clientRunId 只对 pending run 重新触发领取且由数据库 CAS 防止重复上游；浏览器断开不 abort；显式取消先持久化再局部加速。

## 成员清单

- `route.ts`：`POST /api/chat/runs`。
- `[runId]/`：run snapshot、events 和 cancel 动态资源。

**触发器**：调度、幂等、wire、事件或取消语义变化时同步本文档、上级地图和 chat-http.md。
