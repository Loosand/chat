# Folder: apps/web/app/api/chat/runs/[runId]

1. **地位**：单个 owner-scoped chat run 的刷新恢复资源。
2. **逻辑**：GET 返回最新 run 与 assistant checkpoint；子资源提供有限 SSE long-poll 和显式取消。
3. **约束**：不返回 route topology、owner 或隐藏 reasoning；不存在/他人 run 统一 404。

## 成员清单

- `route.ts`：`GET /api/chat/runs/:runId` snapshot。
- `events/`：可从 sequence cursor 重订阅的有限 SSE。
- `cancel/`：幂等显式取消。

**触发器**：snapshot、子资源或授权语义变化时同步本文档、父地图和 chat-http.md。
