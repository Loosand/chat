# Folder: apps/web/app/api/chat/runs/[runId]/events

1. **地位**：可刷新/断线重订阅的 chat run Server-Sent Events 入口。
2. **逻辑**：以 `after` sequence 读取 PostgreSQL important events 和最新 run/assistant snapshot，有限 long-poll 后要求客户端重连。
3. **约束**：订阅 signal 只终止读取循环，不传给执行器；不永久保存/发送逐 token delta，不泄漏内部 route 或 hidden reasoning。

## 成员清单

- `route.ts`：`GET /api/chat/runs/:runId/events?after=N`。
- `route.test.ts`：SSE 首帧、终态关闭与订阅断开不继续读取 contract。

**触发器**：SSE event 名、cursor、poll/timeout 或恢复语义变化时同步本文档、父地图和 chat-http.md。
