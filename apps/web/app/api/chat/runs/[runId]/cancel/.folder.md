# Folder: apps/web/app/api/chat/runs/[runId]/cancel

1. **地位**：chat run 的显式、幂等用户取消命令。
2. **逻辑**：POST 先将 PostgreSQL run 写为 cancel_requested，再通知同进程 manager Abort；跨实例 executor 通过数据库监察发现。
3. **约束**：必须验证 session/Origin；局部 manager 不是权威状态。
