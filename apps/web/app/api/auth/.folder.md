# Folder: apps/web/app/api/auth

1. **地位**：Better Auth 的 App Router HTTP 挂载目录。
2. **逻辑**：catch-all route 在请求时取得惰性 auth runtime，并将标准 Request 交给 Better Auth handler。
3. **约束**：不得在 route import 时解析环境或连接数据库；GET/POST 以外的方法不开放。

## 成员清单

- `[...all]/`：`/api/auth/*` catch-all Route Handler。

**触发器**：base path、方法、运行时或 composition root 变化时，同步本文档、父目录地图与认证文档。
