# Folder: apps/web/app/chat

1. **地位**：认证用户的新聊天与持久 conversation 入口。
2. **逻辑**：Server Component 先读取权威 Better Auth session 和公开模型，再装配空白或带 snapshot 的 ChatWorkspace。
3. **约束**：不得信任客户端 owner；页面始终由 server session gate 保护；具体 conversation 使用子路由刷新恢复。

## 成员清单

- `[conversationId]/`：持久 conversation 首屏与 active run 刷新恢复入口。
- `error.tsx`：不泄漏内部异常的 segment 重试边界。
- `not-found.tsx`：统一 conversation 不存在/越权缺失页。
- `page.tsx`：受保护的新聊天工作区入口。

**触发器**：session gate、聊天页面职责或子路由变化时同步本文档、父地图和 auth/frontend 文档。
