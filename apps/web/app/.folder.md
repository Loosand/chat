# Folder: apps/web/app

1. **地位**：Next.js App Router 的页面、根布局与 HTTP Route Handler 入口。
2. **逻辑**：`layout.tsx` 建立页面元数据和全局样式，公开认证页面装配 Better Auth 浏览器表单，`api/` 装配 HTTP 边界。
3. **约束**：默认 Server Component；保持单一 `h1`、语义 HTML、键盘可达和真实状态文案。

## 成员清单

- `api/`：Better Auth 与 owner-scoped chat JSON/SSE Route Handler，成员见其 `.folder.md`。
- `chat/`：由权威 server session 保护的新聊天、持久 conversation 与 active run 刷新恢复入口。
- `sign-in/`、`sign-up/`：邮箱密码登录、注册与验证引导。
- `forgot-password/`、`reset-password/`：防枚举密码恢复与 token 更新。
- `layout.tsx`：根 HTML、metadata 和全局样式入口。
- `page.tsx`：项目欢迎页与登录/注册入口。
- `globals.css`：Tailwind 扫描与 Lerpwind 插件入口，以及首页、认证页面和聊天工作区的 viewport-fluid 布局样式。

**触发器**：增加路由、修改根布局、页面职责或全局样式入口时同步更新本文档。
