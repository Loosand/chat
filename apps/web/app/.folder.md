# Folder: apps/web/app

1. **地位**：Next.js App Router 的根布局与最小首页。
2. **逻辑**：`layout.tsx` 建立页面元数据和全局样式，`page.tsx` 展示当前工程状态。
3. **约束**：默认 Server Component；保持单一 `h1`、语义 HTML、键盘可达和真实状态文案。

## 成员清单

- `layout.tsx`：根 HTML、metadata 和全局样式入口。
- `page.tsx`：M0 项目欢迎页。
- `globals.css`：Tailwind 扫描入口和 Web 页面布局样式。

**触发器**：增加路由、修改根布局、页面职责或全局样式入口时同步更新本文档。
