# Folder: packages/model-router/src

1. **地位**：模型目录与 owner-scoped 用户供应商连接的领域、应用服务和持久化 port 事实层。
2. **逻辑**：service 校验命令与跨实体不变量，通过 repository port 持久化；供应商服务通过 vault/verifier port 加密密钥并检查连接；network-policy facade 使用共享安全包规范化并检查 URL。
3. **约束**：不引用 ORM、HTTP handler、AI SDK model 或 provider client；明文 credential 只允许短暂进入 vault/verifier port，不得进入公开实体、日志或 repository；完整加权/failover/circuit 不在本阶段实现。

## 成员清单

- `errors.ts`：模型目录安全公开错误码与类型守卫。
- `index.ts`：model-router package 公共导出。
- `model.ts`：四层目录实体、公开模型与 resolved route 快照类型。
- `network-policy.ts`：共享 `@repo/network-security` 到模型目录安全错误的 facade。
- `network-policy.test.ts`：URL、DNS、IPv4/IPv6 与显式私网开关的安全测试。
- `provider-connection-errors.ts`：供应商连接输入、凭证和持久化的安全错误码。
- `provider-connection-model.ts`：五个 preset 定义、公开连接实体与密文持久化记录。
- `provider-connection-ports.ts`：供应商 repository、credential vault、verifier、clock 与 ID ports。
- `provider-connection-service.ts`：owner-scoped 保存、读取、删除与连通性检查用例。
- `provider-connection-service.test.ts`：owner 隔离、密钥遮蔽、URL 校验与检查结果的服务测试。
- `ports.ts`：repository、时钟、ID、写入结果与候选 route ports。
- `service.ts`：受校验 CRUD、公开目录读取和确定性单-route 解析。
- `service.test.ts`：CRUD、task compatibility、乐观并发映射和多 route fail-closed 单元测试。

**触发器**：成员、命令、实体、port、preset、安全策略或 resolver 语义变化时同步本文档和 `docs/architecture/model-catalog.md`。
