# Folder: packages/model-router/src

1. **地位**：模型目录实体、管理命令、持久化 port 和最小 route 解析的事实层。
2. **逻辑**：service 校验命令与跨实体不变量，通过 repository port 持久化；network-policy 规范化 Upstream URL 并提供调用前 DNS 检查。
3. **约束**：不引用 ORM、HTTP handler、AI SDK model、provider client 或 secret value；完整加权/failover/circuit 不在本阶段实现。

## 成员清单

- `errors.ts`：模型目录安全公开错误码与类型守卫。
- `index.ts`：model-router package 公共导出。
- `model.ts`：四层目录实体、公开模型与 resolved route 快照类型。
- `network-policy.ts`：Upstream base URL 规范化、特殊 IP 拒绝与调用前 DNS policy。
- `network-policy.test.ts`：URL、DNS、IPv4/IPv6 与显式私网开关的安全测试。
- `ports.ts`：repository、时钟、ID、写入结果与候选 route ports。
- `service.ts`：受校验 CRUD、公开目录读取和确定性单-route 解析。
- `service.test.ts`：CRUD、task compatibility、乐观并发映射和多 route fail-closed 单元测试。

**触发器**：成员、命令、实体、port、安全策略或 resolver 语义变化时同步本文档和 `docs/architecture/model-catalog.md`。
