# Folder: packages/model-router

1. **地位**：模型目录、用户供应商连接、管理用例与 route 解析规则 package。
2. **逻辑**：`src` 用稳定 contracts 定义实体、repository/vault/verifier port、安全策略与 service，由 database 和 Web composition root 注入实现。
3. **约束**：不得依赖 Next.js、AI SDK、Drizzle、Redis、计费或任务实现；不得读取环境 secret，明文 credential 只可短暂流经注入的 vault/verifier port。

## 成员清单

- `package.json`：`@repo/model-router` 公共出口、依赖与质量脚本。
- `src/`：模型目录领域、ports、service 与网络目标策略。
- `tsconfig.json`：严格 TypeScript package 配置。

**触发器**：package 依赖、公共入口、脚本或顶层成员变化时同步本文档、`packages/.folder.md`、`AGENTS.md` 和模型目录架构文档。
