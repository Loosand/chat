# Folder: packages/contracts/src

1. **地位**：Chat 无框架依赖的公共 contract 根，当前只保存项目身份和部署 profile schema。
2. **逻辑**：用常量、TypeScript 类型与 Zod schema 为 Web、adapter 和未来任务提供同一边界。
3. **约束**：不得依赖 Next.js、数据库、AI SDK、缓存、存储或任务实现。

## 成员清单

- `index.ts`：项目身份和部署 profile 的公共导出。

**触发器**：新增公共 schema、错误码或稳定枚举时同步更新本文档；领域增长后按职责拆文件。
