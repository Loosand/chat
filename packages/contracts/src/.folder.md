# Folder: packages/contracts/src

1. **地位**：Chat 无框架依赖的公共 contract 根，保存跨应用、领域和 adapter 的稳定值。
2. **逻辑**：用常量、TypeScript 类型与 Zod schema 统一项目身份、部署 profile 和聊天 wire/storage contract。
3. **约束**：不得依赖 Next.js、数据库、AI SDK、缓存、存储或任务实现。

## 成员清单

- `chat.ts`：品牌 ID、版本化消息内容、run/message 状态、事件、usage 与失败 schema。
- `chat-api.ts` / `.test.ts`：聊天 HTTP strict command、JSON resource、SSE snapshot 与公开错误 contract。
- `model-catalog.ts`：稳定 protocol、task、provider family、capability 与环境 secret reference contract。
- `model-catalog.test.ts`：模型目录标识、capability 和 secret reference 边界测试。
- `index.ts`：项目身份、部署 profile、聊天和模型目录 contract 的公共导出。

**触发器**：新增公共 schema、错误码或稳定枚举时同步更新本文档；领域增长后按职责拆文件。
