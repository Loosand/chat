# Folder: packages/next-config/src

1. **地位**：全部 Next.js 应用共享的构建与运行配置入口。
2. **逻辑**：导出 typed routes、standalone 输出和内部 UI package 转译设置，由 `apps/web/next.config.ts` 直接复用。
3. **约束**：只放跨应用稳定配置；不得读取业务数据、密钥或数据库。

## 成员清单

- `index.ts`：共享 `NextConfig` 唯一导出。

**触发器**：Next.js runtime、构建输出、实验特性或转译 package 变化时同步更新本文档、Web 地图和 `design.md`。
