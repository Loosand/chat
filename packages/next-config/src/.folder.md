# Folder: packages/next-config/src

1. **地位**：全部 Next.js 应用共享的构建与运行配置入口。
2. **逻辑**：导出 typed routes、内部 UI package 转译和平台感知输出；Vercel 使用框架原生产物，其他环境生成 standalone。
3. **约束**：只读取 Vercel 自动提供的非敏感平台标记；不得读取业务数据、密钥或数据库。

## 成员清单

- `index.ts`：共享 `NextConfig` 唯一导出，按 `VERCEL=1` 切换部署产物。

**触发器**：Next.js runtime、构建输出、实验特性或转译 package 变化时同步更新本文档、Web 地图和 `design.md`。
