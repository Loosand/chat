# Folder: packages/ai/src

1. **地位**：AI SDK 7 与精确 provider/protocol adapter 的纯模型调用边界。
2. **逻辑**：registry 按稳定 family + protocol 建立模型，guarded fetch 执行请求网络约束，`streamChatText` 提供单 attempt 流并归一化 usage。
3. **约束**：不访问数据库、缓存、计费、任务系统或 Next.js；不负责选择平台 route、解析环境 secret 或 route failover。

## 成员清单

- `errors.ts`：不泄露 credential/provider body 的稳定 adapter 错误。
- `guarded-fetch.ts` / `.test.ts`：同源/base-path、逐请求复验和 manual redirect 边界。
- `stream-chat-text.ts` / `.test.ts`：prompt/messages/system/abort 与零 SDK 重试的流式调用。
- `text-model-adapter.ts` / `.test.ts`：七种首批文本 family/protocol 映射和真实 provider 发包 contract。
- `usage.ts` / `.test.ts`：AI SDK usage 到稳定 contract 的归一化。
- `index.ts`：AI package 公共导出。

**触发器**：模型输入输出、provider、协议或公共导出变化时同步更新本文档、文件 Header 和相关架构文档。
