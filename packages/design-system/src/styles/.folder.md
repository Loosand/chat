# Folder: packages/design-system/src/styles

1. **地位**：跨应用共享的 shadcn/ui 主题、Chat 工具类、流式 Markdown 和基础元素样式事实源。
2. **逻辑**：`globals.css` 把 Base Rhea token 映射到 Tailwind v4，导入 shadcn/Streamdown/KaTeX CSS 并声明插件扫描范围。
3. **约束**：只使用语义变量；不加入页面业务布局、无语义渐变、发光或毛玻璃。

## 成员清单

- `globals.css`：Base Rhea 主题、Chat utilities、Streamdown/KaTeX、共享 token、reset 和 Panel 样式。

**触发器**：token、暗色模式、基础元素或 primitive 样式变化时同步更新本文档和根 `design.md`。
