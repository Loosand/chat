# Folder: packages/design-system/src/styles

1. **地位**：跨应用共享的颜色、排版和基础元素样式事实源。
2. **逻辑**：`globals.css` 定义 light/dark 语义 token，并为 Panel primitive 提供基础样式。
3. **约束**：只使用语义变量；不加入页面业务布局、无语义渐变、发光或毛玻璃。

## 成员清单

- `globals.css`：共享 token、reset 和 Panel 样式。

**触发器**：token、暗色模式、基础元素或 primitive 样式变化时同步更新本文档和根 `design.md`。
