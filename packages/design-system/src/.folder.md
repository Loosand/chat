# Folder: packages/design-system/src

1. **地位**：Chat 的共享 UI primitive 与语义 token 起点。
2. **逻辑**：`index.tsx` 导出无业务状态的 Panel，`styles/` 提供全局 token 和基础元素样式。
3. **约束**：不包含聊天、计费或管理业务；页面不得复制已有 primitive 或另建颜色系统。

## 成员清单

- `index.tsx`：共享 Panel primitive。
- `styles/`：全局语义 token 与基础 CSS。

**触发器**：primitive、公共导出、token 或基础样式变化时同步更新本文档、styles 地图和 `design.md`。
