# Folder: packages/design-system/src

1. **地位**：Chat 的 shadcn/ui Base Rhea + Base UI primitive、流式文本 renderer 与语义 token 起点。
2. **逻辑**：`components/` 保存仓库拥有的基础组件和 StreamingMarkdown，`lib/` 提供 helper，`index.tsx` 汇总稳定根出口，`styles/` 提供主题与第三方扫描入口。
3. **约束**：不包含聊天、计费或管理业务；不得混入 Radix-only primitive；页面不得复制已有组件或另建颜色系统。

## 成员清单

- `components/`：shadcn/ui + Base UI Chat primitives 与 Streamdown renderer 源码。
- `index.tsx`：Panel、Button 与工具的公共导出入口。
- `lib/`：shadcn/ui 共用的无状态 helper。
- `styles/`：全局语义 token、shadcn Chat 工具类与 Streamdown/KaTeX CSS。

**触发器**：primitive、公共导出、token 或基础样式变化时同步更新本文档、styles 地图和 `design.md`。
