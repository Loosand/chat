# Folder: packages/design-system/src/components

1. **地位**：仓库直接拥有的 shadcn/ui Base Rhea + Base UI primitive 与 AI 文本 renderer 源码目录。
2. **逻辑**：组件组合 Base UI、`@shadcn/react`、CVA、Streamdown 和共享语义 token，再通过 package subpath exports 暴露。
3. **约束**：保持无业务状态；不得引入 Radix-only API、页面数据获取或领域规则。

## 成员清单

- `attachment.tsx`：附件状态、媒体、操作与横向附件组 primitive。
- `alert.tsx`：认证/请求等状态与错误的可访问提示 primitive。
- `bubble.tsx`：消息气泡表面、分组和 reaction 容器 primitive。
- `button.tsx`：Base UI 驱动的 Rhea Button primitive。
- `card.tsx`：表单和分组内容的 Base Rhea Card 组合 primitive。
- `input.tsx`：Base UI 驱动的单行输入 primitive。
- `label.tsx`：可访问表单标签 primitive。
- `marker.tsx`：系统状态、日期和分隔标记 primitive。
- `message-scroller.tsx`：流式跟随、锚点、历史前插与可见性滚动行为。
- `message.tsx`：无状态消息行布局 primitive。
- `streaming-markdown.tsx`：CJK、数学、按需代码/Mermaid 的安全流式 Markdown renderer。

**触发器**：组件增删、公开 props、variant、底层 primitive 或导出路径变化时更新本文档、上级地图和 `components.json`。
