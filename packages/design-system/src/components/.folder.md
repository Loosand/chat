# Folder: packages/design-system/src/components

1. **地位**：仓库直接拥有的 shadcn/ui + Base UI primitive 源码目录。
2. **逻辑**：组件组合 Base UI 行为、CVA variants、`cn` 和共享语义 token，再通过 package exports 暴露。
3. **约束**：保持无业务状态；不得引入 Radix-only API、页面数据获取或领域规则。

## 成员清单

- `button.tsx`：Base UI 驱动的 shadcn Button primitive。

**触发器**：组件增删、公开 props、variant、底层 primitive 或导出路径变化时更新本文档、上级地图和 `components.json`。
