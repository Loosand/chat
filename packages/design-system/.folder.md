# Folder: packages/design-system

1. **地位**：Chat 的共享组件 workspace，也是 shadcn/ui CLI 的 Monorepo 安装目标。
2. **逻辑**：`components.json` 路由 Base UI 组件源码到 `src/`，package imports/exports 提供包内和跨 workspace 的稳定路径。
3. **约束**：`style`、`baseColor` 与 `iconLibrary` 必须和 `apps/web/components.json` 一致；不保存页面业务组件。

## 成员清单

- `components.json`：shadcn/ui Base UI 共享 workspace 配置。
- `package.json`：组件依赖、package imports 与公共 exports。
- `src/`：组件、工具和主题源码。
- `tsconfig.json`：共享组件 TypeScript 配置。

**触发器**：shadcn style/base、安装路径、package export、依赖或源码目录变化时更新本文档和 Web 配置。
