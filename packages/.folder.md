# Folder: packages

1. **地位**：框架无关 contract、基础设施 adapter、共享 UI 与工程配置的集合。
2. **逻辑**：内部包使用 `@repo/*` 与 `workspace:*` 组成向内依赖图，由应用入口负责装配。
3. **约束**：禁止反向依赖 `apps/*`、跨包读取未导出文件或提前创建没有真实职责的空领域包。

## 成员清单

- `contracts/`：公共 contract。
- `chat/`：无基础设施聊天领域、状态机、ports 与应用服务。
- `auth/`：Better Auth 首期功能配置、server/client factory 与稳定 OwnerId 映射。
- `ai/`：AI SDK 边界。
- `database/`：PostgreSQL 连接、聊天/auth 事实 schema、migration 与 repository adapter 边界。
- `cache/`：缓存和事件 primitive。
- `storage/`：对象存储 port。
- `jobs/`：后台任务 driver contract。
- `logger/`：结构化日志。
- `design-system/`：shadcn/ui Base Rhea + Base UI、Chat primitives、Streamdown 和共享主题。
- `next-config/`：共享 Next.js 配置。
- `typescript-config/`：共享 TypeScript 配置。

**触发器**：package 增删、改名、职责或依赖方向变化时，同步更新本文档、根 README、`AGENTS.md` 和 `design.md`。
