# Folder: packages/chat/src

1. **地位**：Chat 的无基础设施领域模型与应用服务核心。
2. **逻辑**：contracts 定义 wire/storage 值，状态机保护 run 生命周期，service 通过 repository/clock/ID ports 编排用例。
3. **约束**：不得依赖 Next.js、AI SDK、Drizzle、Redis、Trigger 或具体 provider；所有外部实现经 ports 注入。

## 成员清单

- `errors.ts`：稳定聊天领域错误码与错误类型。
- `id.ts`：默认 UUID 与系统时钟 adapter。
- `index.ts`：chat package 公共导出。
- `model.ts`：Conversation、Message、ChatRun、RunEvent 领域记录。
- `ports.ts`：repository、clock、ID 的依赖倒置 contract。
- `run-state-machine.ts`：run 合法转换、终态和消息状态映射。
- `run-state-machine.test.ts`：run 生命周期不变量的可执行规范。
- `service.ts`：创建会话、准备 turn、checkpoint、转换和读取用例。
- `service.test.ts`：应用服务命令、状态校验和并发 guard 的可执行 contract。

**触发器**：成员、领域状态、port、用例或公共导出变化时同步本文档和 `docs/architecture/chat-core.md`。
