# Folder: packages/chat

1. **地位**：聊天领域与应用服务 package，保护业务事实不被框架和基础设施实现污染。
2. **逻辑**：`src` 提供模型、状态机、ports 与用例，workspace 配置只声明 contracts 依赖和质量任务。
3. **约束**：不得依赖 Next.js、AI SDK、数据库、缓存、存储或任务 SDK；adapter 通过 ports 注入。

## 成员清单

- `package.json`：`@repo/chat` 导出、依赖与质量脚本。
- `src/`：聊天领域和应用服务源码。
- `tsconfig.json`：严格 TypeScript package 配置。

**触发器**：package 依赖、公共入口、脚本或顶层成员变化时同步本文档、`packages/.folder.md` 和架构文档。
