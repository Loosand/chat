# Folder: packages/logger/src

1. **地位**：结构化应用日志的框架中立 contract；当前提供安全的 no-op 实现供装配测试。
2. **逻辑**：调用方只依赖带 context 的四级 Logger，后续 adapter 可连接 Pino/OpenTelemetry。
3. **约束**：普通日志不替代审计、用量账本或系统事件；不得记录密钥和完整敏感内容。

## 成员清单

- `index.ts`：Logger contract、context 和 no-op logger。

**触发器**：日志字段、级别、redaction 或 provider adapter 变化时同步更新本文档和可观测性设计。
