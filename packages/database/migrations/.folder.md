# Folder: packages/database/migrations

1. **地位**：PostgreSQL schema 的版本化、可审计演进历史。
2. **逻辑**：SQL migration 与 Drizzle `meta/` 快照成对提交，由 `db:migrate` 显式应用。
3. **约束**：禁止运行时自动迁移未知数据库；migration 一旦发布不得改写，只能追加新版本。

## 成员清单

- `0000_massive_king_cobra.sql`：Goal 1 聊天核心四张事实表及约束的初始 migration。
- `0001_wandering_toro.sql`：Goal 2 Better Auth core 与 Admin plugin 表、索引及外键。
- `0002_steep_lady_deathstrike.sql`：Better Auth 跨实例数据库限流表与唯一键。
- `meta/`：Drizzle migration journal 与 schema 快照；由 drizzle-kit 生成。

**触发器**：migration 新增、重命名、基线策略或生成工具变化时同步本文档和数据库架构文档。
