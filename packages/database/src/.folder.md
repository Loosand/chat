# Folder: packages/database/src

1. **地位**：Drizzle/PostgreSQL 连接、聊天/认证/模型目录事实 schema 与 repository adapter 的基础设施边界。
2. **逻辑**：显式接收连接字符串并装配 schema；版本化 migration 建表，adapter 事务化实现领域 port，Better Auth CLI 生成认证表定义。
3. **约束**：不得在模块加载时连接数据库；schema 只能通过已审查的版本化 migration 演进。

## 成员清单

- `client.ts`：惰性 PostgreSQL/Drizzle 连接工厂、显式 pool 上限和关闭入口。
- `auth-schema.ts`：由 `@repo/auth` 配置生成的 Better Auth core/Admin/数据库限流 Drizzle schema。
- `chat-repository.ts`：ChatRepository 的事务、幂等、乐观并发与持久化映射实现。
- `chat-repository.integration.test.ts`：adapter 原子性、rollback、幂等、CAS、owner 与分支集成测试。
- `chat-service.integration.test.ts`：ChatService 到 migration 数据库的纵向恢复与并发 contract 测试。
- `index.ts`：database package 公共导出。
- `model-catalog-schema.ts`：Upstream、绑定、Platform Model 与 Route 四层模型目录 schema。
- `model-catalog-schema.migration.test.ts`：模型目录全量 migration、身份、约束、外键与 JSON 快照集成测试。
- `schema.ts`：聊天事实表、外键、唯一键、check 与索引的 Drizzle schema。
- `auth-schema.migration.test.ts`：通过 PGlite 验证认证表、Admin 字段、唯一键、限流 key 和级联行为。
- `schema.migration.test.ts`：通过 PGlite 执行 migration 和聊天核心数据库约束。

**触发器**：连接策略、schema、migration、repository 或公共导出变化时同步更新本文档和数据库架构文档。
