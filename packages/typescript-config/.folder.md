# Folder: packages/typescript-config

1. **地位**：Monorepo TypeScript strict 配置事实源；本目录不包含运行时代码。
2. **逻辑**：`base.json` 服务普通 package，`nextjs.json` 在其上增加 App Router 与 Bundler 配置。
3. **约束**：不得为通过检查而全局放宽 strict；特殊例外应留在具体 package。

## 成员清单

- `base.json`：ES2022、NodeNext 和 strict 基线。
- `nextjs.json`：Next.js、JSX、Bundler 与内部包路径配置。
- `package.json`：共享配置 package 声明。

**触发器**：编译目标、严格性、模块解析或共享路径变化时同步更新本文档和受影响 package。
