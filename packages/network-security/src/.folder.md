# Folder: packages/network-security/src

1. **地位**：不可信外部 HTTP(S) 目标的共享 SSRF 与 DNS rebinding 防线。
2. **逻辑**：`policy.ts` 负责 URL/DNS 校验，`pinned-fetch.ts` 在实际 socket lookup 时复验并固定已检查地址。
3. **约束**：仅供 server runtime 使用；不包含模型、MCP、存储或下载业务规则，不持有 credential。

## 成员清单

- `errors.ts`：不泄露目标细节的稳定网络安全错误。
- `policy.ts`：base URL、请求 URL 与 IP range 策略。
- `pinned-fetch.ts`：基于 Undici connector lookup 的连接时校验与可选进程级清理。
- `index.ts`：package 公共导出。

**触发器**：URL、DNS、IP range、redirect 或连接器策略变化时同步本文档、文件 Header、测试和 `docs/architecture/network-security.md`。
