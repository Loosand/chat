# Folder: packages/network-security

1. **地位**：共享 server-only SSRF 与 DNS rebinding 防线 package。
2. **逻辑**：`src` 提供无业务语义的 URL/address policy 和 Node pinned transport，供模型、AI 与未来外部 HTTP adapter 复用。
3. **约束**：不得依赖应用领域包、Web、数据库或 credential；不得导出绕过校验的 connector。

## 成员清单

- `package.json`：`@repo/network-security` 公共出口、Undici/IP 依赖与质量脚本。
- `src/`：共享错误、URL/DNS policy、pinned fetch 与测试。
- `tsconfig.json`：严格 TypeScript package 配置。

**触发器**：package 依赖、公共出口、运行时支持或顶层成员变化时同步本文档、`packages/.folder.md` 和 `docs/architecture/network-security.md`。
