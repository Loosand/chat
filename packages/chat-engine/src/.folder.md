# Folder: packages/chat-engine/src

1. **地位**：可部署到 Web `after()`、独立 worker 或未来任务系统的聊天 run 执行核心。
2. **逻辑**：runner 只消费稳定 ports；AI SDK adapter 和 environment resolver 是可替换的边缘实现。
3. **约束**：run/消息/事件以 ChatService 为权威；route snapshot 不含密钥；provider raw 数据不跨边界。

## 成员清单

- `ai-sdk-generation.ts` / `.test.ts`：Resolved route 到 `@repo/ai` 的稳定 generation event adapter 与 AI SDK 官方 mock contract。
- `errors.ts`：执行器安全错误与稳定错误码。
- `index.ts`：package 公共导出。
- `ports.ts`：聊天存储、路由、generation、secret、clock/sleep ports。
- `runner.ts`：route 固定、历史转换、checkpoint、DB 取消监察和终态编排。
- `runner.test.ts`：成功、取消、失败净化与 secret snapshot 可执行 contract。
- `secret-resolver.ts`：环境变量 secret reference 的 fail-closed adapter。
- `secret-resolver.test.ts`：secret 缺失与非泄漏回归覆盖。

**触发器**：成员、执行阶段、失败/取消语义或公共 port 变化时同步本文档和 `docs/architecture/chat-execution.md`。
