# Folder: packages/chat-engine

1. **地位**：聊天事实、模型目录和 AI SDK adapter 之间的可替换执行编排层。
2. **逻辑**：`src` 固定 route snapshot、解析 secret reference、转换历史、消费模型事件、checkpoint 并收敛终态。
3. **约束**：不依赖 Next.js、Drizzle、Redis 或 Trigger；浏览器连接不是执行生命周期所有者，secret value 不得进入快照、事件或错误。

## 成员清单

- `package.json`：`@repo/chat-engine` 导出、内部 package 依赖与质量脚本。
- `src/`：执行器、AI SDK generation adapter、secret resolver、ports 与测试。
- `tsconfig.json`：严格 TypeScript package 配置。

**触发器**：package 依赖、执行职责或成员变化时同步本文档、`packages/.folder.md` 和 `docs/architecture/chat-execution.md`。
