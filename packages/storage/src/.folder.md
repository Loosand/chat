# Folder: packages/storage/src

1. **地位**：Vercel Blob、S3-compatible 与 Local filesystem 未来共同实现的对象存储 port。
2. **逻辑**：当前定义对象写入、读取、元数据和删除 contract，不绑定具体 SDK。
3. **约束**：只处理 object；不决定文件所有权、配额、审核或业务状态。

## 成员清单

- `index.ts`：ObjectStore 输入、引用、元数据与操作 contract。

**触发器**：对象生命周期、流式读写、签名 URL 或 provider adapter 变化时同步更新本文档和存储架构说明。
