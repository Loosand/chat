# Folder: packages/auth

1. **地位**：Better Auth 的框架无关身份组合边界，隔离认证库类型与聊天领域。
2. **逻辑**：固定首期邮箱密码、验证、数据库限流和 Admin plugin 配置；server factory 注入 Drizzle 与邮件 dispatcher，client factory 提供 React/Admin 客户端。
3. **约束**：不得在 import 阶段读取环境变量或连接数据库；不得把 session token、密码或验证 token 映射到领域对象。

## 成员清单

- `auth.config.ts`：仅供 Better Auth CLI 生成 Drizzle schema 的配置入口。
- `package.json`：Better Auth 1.6、Drizzle adapter、CLI 与包导出。
- `scripts/`：可复现的 Better Auth CLI schema 生成与 Header/格式化封装，成员见其 `.folder.md`。
- `src/`：配置、server/client factory、OwnerId 映射与测试，成员见其 `.folder.md`。
- `tsconfig.json`：严格 TypeScript 配置。

**触发器**：认证方法、plugin、邮件语义、身份映射、公共导出或生成链路变化时，同步本文档、`docs/architecture/auth.md`、database schema/migration 和调用方。
