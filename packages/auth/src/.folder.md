# Folder: packages/auth/src

1. **地位**：认证 feature、server/client composition 与领域身份适配的实现目录。
2. **逻辑**：共享 feature options 同时驱动 CLI 和运行时；server/client 通过子路径导出，根入口只暴露安全 contract 与 mapper。
3. **约束**：不得读取环境变量、创建数据库连接或把 token/密码写入领域 contract；插件必须保持 server/client/schema 对称。

## 成员清单

- `feature-options.ts`：邮箱密码、验证、UUID identity、Admin plugin 与邮件 dispatcher contract。
- `identity.ts`：Better Auth user id 到 `OwnerId` 的唯一映射。
- `identity.test.ts`：OwnerId 映射与长度边界回归。
- `server.ts`：显式依赖注入的 PostgreSQL Better Auth factory。
- `server.test.ts`：build-safe 组合、secret 与 origin 边界测试。
- `client.ts`：React/Admin auth client factory。
- `index.ts`：框架无关根公共导出。

**触发器**：认证功能、插件、运行配置、身份映射或公共导出变化时，同步本文档、父目录地图、schema/migration 与 `docs/architecture/auth.md`。
